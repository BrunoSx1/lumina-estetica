TIRE SUAS DÚVIDAS

Perguntas frequentes.

Saiba como funciona a proposta de atendimento e agendamento da Lumina Estética.

Como faço para solicitar um horário?

Escolha o tratamento e preencha o formulário de contato com a data desejada.

O agendamento é confirmado automaticamente?

Não. O formulário prepara uma solicitação. Um horário só poderá ser confirmado pelo estabelecimento.

Como escolher o tratamento ideal?

Consulte a descrição dos tratamentos e, em uma clínica real, converse com um profissional qualificado para receber orientação.

Posso solicitar outro horário?

Sim. Você pode preparar uma nova solicitação com outra data e período desejado.

Este site representa uma clínica real?

Não. A Lumina Estética é um projeto fictício de demonstração desenvolvido para portfólio profissional.
