
# 🌸 Lumina Estética

Website responsivo para um studio fictício de estética,
desenvolvido como projeto de portfólio profissional.

## Sobre o projeto

A Lumina Estética apresenta uma interface moderna,
elegante e responsiva, utilizando tons de creme e rosé.

O projeto demonstra habilidades em desenvolvimento
front-end, manipulação do DOM, formulários e acessibilidade.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- CSS Grid e Flexbox
- Intersection Observer API

## Funcionalidades

- Layout responsivo
- Menu mobile interativo
- Hero com fotografia
- Seis tratamentos com filtros por categoria
- Galeria de fotografias
- Perguntas frequentes expansíveis
- Formulário de pré-agendamento
- Validação de campos e datas
- Mensagem personalizada de agendamento
- Integração configurável com WhatsApp
- Animações durante a rolagem
- SEO e acessibilidade básicos

## Como executar

1. Clone ou baixe o repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra index.html no navegador ou com Live Server.

Não é necessário instalar dependências.

## Agendamento

O formulário funciona em modo demonstrativo.

Ao selecionar um tratamento e preencher os campos,
o JavaScript gera uma mensagem personalizada.

Nenhum agendamento real é confirmado pelo site.

Para utilizar um WhatsApp autorizado, configure
a constante WHATSAPP_NUMBER no script.js.
